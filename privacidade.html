Política de Privacidade

Última atualização: 6 de novembro de 2026

Esta política explica como o app Sem Lag (a ferramenta de publicação do canal Sem Lag) usa dados. O app é de uso interno: ele só é usado pelo responsável pelo canal, nas contas do próprio Sem Lag.

1. Quais dados o app acessa

  • YouTube (Google): com a autorização do dono do canal, o app usa a YouTube Data API para enviar vídeos ao canal @semlagcortes e ler os dados básicos do próprio canal (nome e identificador), para confirmar que está publicando no canal certo.
  • Instagram e Facebook (Meta): com a autorização do dono da conta, o app usa a API da Meta para publicar Reels no Instagram @semlag.gg e ler os dados básicos dessa conta e da Página do Facebook ligada a ela.

O app não acessa dados de espectadores, seguidores ou de qualquer outra pessoa, não lê mensagens e não acessa outras contas.

2. Como os dados são usados

Os dados são usados apenas para publicar os vídeos do Sem Lag e registrar o que já foi publicado (identificador e link de cada post). Nada é vendido, compartilhado com terceiros ou usado para publicidade.

3. Onde os dados ficam

Os tokens de acesso e o registro de publicações ficam guardados apenas no computador do responsável pelo canal, fora de qualquer serviço de nuvem do app. Não existe servidor do app nem banco de dados online.

4. Uso de dados das APIs do Google

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app usa os Serviços de API do YouTube; ao usá-lo, aplicam-se também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

5. Como revogar o acesso

  • Google/YouTube: em myaccount.google.com/permissions, remova o acesso do app "Sem Lag".
  • Meta: em Configurações do Facebook → Integrações comerciais, remova o app "Sem Lag Postagem".

Ao revogar, o app perde o acesso imediatamente. Para apagar o registro local de publicações, basta pedir pelo e-mail abaixo.

6. Retenção e exclusão

Os tokens são mantidos enquanto o app estiver em uso e apagados quando o acesso é revogado. O registro de publicações é mantido para evitar postagens duplicadas e pode ser apagado a qualquer momento a pedido.
